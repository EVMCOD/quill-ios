# Quill App Icon — design spec

The icon is generated by Xcode from a 1024×1024 PNG with no alpha channel.

## Design direction

**Concept:** a Reminders-style white paper card with three colored article-rows representing Inbox / Library / Highlights — i.e. the same vocabulary you see when you open the app. A small diagonal **feather** accent in the top-right corner hints at "writing" without leaning into a literal Quill feather (a literal feather doesn't read well at small sizes).

**Palette:**
- Background: gradient navy `#0B0E18` → `#05070E`
- Top-right corner glow: rose-mauve accent `#7967D4` at 32% opacity → transparent
- Card: off-white `#FBFBFD` → `#EFF1F6` (subtle vertical gradient)
- Stripes (article rows): `accent` blue, `streak` coral, `gold` gold, `accentDeep` deep mauve
- Stripes background tracks: pale `#EEF0F5` at 100%
- Feather accent: brand gradient `#7967D4` → `#6551BC`
- Ink dot (drop of ink on the feather tip): coral `#FB6950`

**Constraints:**
- 1024×1024, sRGB, no transparency.
- Round-cropped by iOS — critical content within radius ~410px.
- Designed to read at 60px (iPhone home screen).

## Files

Drop a `1024×1024` PNG named `AppIcon.png` into `Quill/Resources/Assets.xcassets/AppIcon.appiconset/`. Xcode generates the rest.

## Regenerating

```bash
swift ~/quill-ios/scripts/render-icon.swift
```

The script renders the canonical 1024×1024 + a 512×512 preview on the desktop, then enforces 1024×1024 with `sips` (NSImage on Retina can come back at 2x).

## File locations

- `~/Desktop/Quill-icon.png` — full-resolution
- `~/Desktop/Quill-icon@2x.png` — preview
- `~/quill-ios/Quill/Resources/Assets.xcassets/AppIcon.appiconset/AppIcon.png` — Xcode target

## Palette tokens (mirror `QL.Palette`)

```swift
brand       = sRGB(0.475, 0.404, 0.831)  // #7967D4 (rose-mauve)
brandDeep   = sRGB(0.396, 0.318, 0.737)  // #6551BC
paper       = sRGB(0.984, 0.984, 0.992)  // #FBFBFD
paperSoft   = sRGB(0.937, 0.945, 0.961)  // #EFF1F6
inkSoft     = sRGB(0.10,  0.13,  0.20, alpha 0.55)
navy        = sRGB(0.043, 0.055, 0.071)  // #0B0E18
navyDeep    = sRGB(0.020, 0.027, 0.055)  // #05070E
coral       = sRGB(0.984, 0.412, 0.310)  // #FB6950 (streak / ink dot)
gold        = sRGB(0.961, 0.745, 0.255)  // #F5BE41
```

## Iterating

If the design needs a tweak, edit `scripts/render-icon.swift` and re-run. The Swift + AppKit pipeline keeps the icon fully reproducible: no manual Photoshop step, no missing-source-image, no designer round-trip needed for v1.
